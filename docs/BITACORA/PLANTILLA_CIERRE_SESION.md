# Plantilla Estándar de Cierre de Sesión
## Prisma Business Dashboard - Grupo Prisma S.A.P.I. de C.V.

Esta plantilla debe ser utilizada de forma obligatoria para registrar cada sesión de trabajo en `docs/BITACORA/BITACORA_SESIONES.md`. Cada uno de los 12 puntos debe completarse con datos reales y objetivos, sin omitir campos ni inventar resultados.

---

```markdown
## SESIÓN #[Número de Sesión]
- **1. Fecha y Hora:** [AAAA-MM-DD HH:MM a HH:MM (Zona Horaria)]
- **2. Fase Actual:** [FASE 0 a FASE 9 - Nombre de la Fase]
- **3. Objetivo de la Sesión:** [Descripción concreta del propósito y meta de la sesión de trabajo]
- **4. Actividades Realizadas:**
  - [Actividad 1 detallada]
  - [Actividad 2 detallada]
  - [Actividad 3 detallada]
- **5. Archivos Creados:**
  - `ruta/al/archivo_1.ext`
  - `ruta/al/archivo_2.ext`
- **6. Archivos Modificados:**
  - `ruta/al/archivo_modificado.ext` (describir brevemente qué se cambió)
- **7. Funcionalidades Terminadas:**
  - [Funcionalidad 1 que cumple con su Definition of Done (DoD)]
  - [Funcionalidad 2 / N/A si fue sesión documental o de refactorización]
- **8. Pruebas Ejecutadas y Resultados Reales:**
  - [Comando ejecutado o método de inspección: ej. `npm test`, `npm run test:e2e`, revisión estática]
  - [Resultado numérico o cualitativo real: ej. 12 pruebas pasadas, 0 fallidas / N/A si no aplica]
- **9. Errores o Problemas Encontrados:**
  - [Descripción del error técnico, ambigüedad o bloqueo detectado, o "Ninguno"]
- **10. Decisiones Tomadas:**
  - [Decisión de arquitectura, diseño o ajuste de negocio consensuado con el Product Owner]
- **11. Actividades Pendientes:**
  - [Tarea 1 que quedó en progreso o pendiente para la fase actual]
  - [Tarea 2]
- **12. Siguiente Actividad Exacta para Continuar:**
  - [Instrucción puntual y unívoca de qué archivo abrir y qué comando o acción ejecutar al reanudar]
```
